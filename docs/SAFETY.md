# 安全与授权边界

本文件描述当前生产执行边界。历史设计稿、临时验收说明和候选能力文件不能扩大这里、`AGENTS.md`、设备操作 Skill、已接受 capability profile 或精确批准计划授予的权限。

## 任务权限

用户任务决定本次有限计划的目标设备、内容来源、动作顺序、次数、条件、预算和并发。模板只能补默认值，不能覆盖用户显式参数。执行前只检查本次选中设备以及本次动作实际需要的能力；其他设备或未使用能力的异常只记诊断，不阻塞任务。

一次精确计划确认是普通执行过程的唯一确认边界。确认后，执行器可连续完成计划中已经编译并展示的有限步骤和恢复分支，不逐步重复询问。

用户任务不能直接绕过动作注册表、已接受能力范围、计划哈希、设备身份、锁、执行槽、操作账本或状态验证。新增自动动作必须先具备闭合参数、页面前置条件、前后状态证明、失败与恢复语义、证据、测试和人工能力验收。

## 自动状态变化

当前生产自动账户状态动作是确保点赞和确保收藏。它们是确保态操作，不是盲目 toggle：已激活时记录 no-op；发送后状态不明确时打开熔断且不得重发。

关注、评论/回复发送、私信、分享、发布、删除以及账号、隐私、安全或身份设置仍是 human-final 或禁止自动化。任务可以把它们显示为人工最终项，但不能把它们编译成设备自动发送步骤。

## 强制停止

遇到以下任一情况必须立即停止并保留当前页面，不得接受、关闭、绕过、重试或换通道继续：

- CAPTCHA、平台风控、异常活动或账号限制；
- 意外登录、身份验证、账号恢复；
- 系统权限或支付/金融确认；
- 私密、受限、消息、联系人或非计划页面；
- 设备、账号、目标或执行通道身份漂移；
- 已发送状态变化的后态无法验证；
- 计划、审批、能力、预算、账本、锁、租约、nonce 或证据完整性失效。

## 设备与感知

- 所有手机操作只通过 `xhs.cmd`；禁止直接调用内部脚本、裸 ADB、私有 API 或效卫 WebSocket。
- 使用每台手机的新鲜 UI 层级和语义节点，不跨设备复用坐标。
- CPA 只返回闭合只读观察，不能返回动作、坐标、路径、URL 或任意指令，也不能单独证明点赞/收藏结果。
- 不使用随机坐标、随机停留、模拟真人、账号养号、互动农场、规避平台控制或设备/网络身份操纵。

## 数据

`.env`、本地配置、`data/`、截图、UI XML、日志、账号/设备真实标识、token、cookie、密钥、私信、联系人和支付信息不得提交或输出。仓库检查只报告私有数据数量，不打印路径。
